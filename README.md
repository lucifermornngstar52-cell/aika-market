# Aika Market

Свой магазин приложений: каталог собирается из GitHub Releases, APK скачиваются одной кнопкой.

- Чистые HTML/CSS/JS, без сборки и зависимостей
- Каталог тянется из API GitHub и кэшируется в localStorage на 10 минут
- PWA: ставится на домашний экран, открывается оффлайн
- Описание, версии и changelog берутся из текста релиза

## Как добавить приложение

1. Залей релиз с APK в свой репозиторий на GitHub
2. Добавь запись в массив `APPS` в `app.js`:

```js
{ repo: 'имя-репозитория', title: 'Название', cat: 'app', icon: '📱',
  grad: ['#5ef2d6', '#a06bff'], desc: 'Описание', web: 'https://ссылка' }
```

3. Пуш в main — сайт обновится сам, новая версия появится в магазине автоматически.

## Категории

`game` — игры, `app` — приложения, `tool` — инструменты, `web` — сайты.
